# Как участвовать

## Главное правило

`skills/koroche-blyat/SKILL.md` — единственный источник смысла. Всё в
`adapters/generated/` выводится из него и **не правится руками**: после любой
правки скилла запустите генератор и закоммитьте результат вместе с ним.

```sh
uv run python -m scripts.generate_adapters
uv run python -m scripts.generate_adapters --check
```

Изменение `SKILL.md` меняет его SHA-256, а значит и список хешей источников в
`scripts/installer/sources.py`, и ожидания в тестах контракта скилла. Проверка
`--check` и полный набор тестов это поймают.

## Перед пул-реквестом

```sh
uv sync --frozen
uv run python -m scripts.generate_adapters --check
uv run python -m scripts.validate
uv run pytest -q
```

Все четыре должны пройти. CI повторит их на Ubuntu и macOS для Python 3.9 и
3.13.

## Python 3.9

Всё, что попадает в пакет — установщик и его модули — работает на Python 3.9
без сторонних зависимостей. Значит `typing.Optional` и `typing.Tuple` вместо
синтаксиса `|`. PyYAML, pytest и jsonschema нужны только для разработки и
оценок.

Проверить руками:

```sh
python3.9 -m py_compile scripts/install.py scripts/installer/*.py
```

## Словарь и справочники

Расширять словарь можно и нужно, но **только своими формулировками**.
Репозиторий `nickname76/russian-swears` стоит в `UPSTREAMS.yml` как
`NOASSERTION` и `distributed: false`: лицензия не выдана, копировать оттуда
нельзя. Отдельные корни русского мата — это язык и никому не принадлежат;
охраняется чужая подборка, определения и примеры.

В `NOTICE.md` и в шапке каждого справочника записано, что они написаны с нуля.
Копирование сделает эти утверждения ложными, а тесты провенанса такое не
поймают — они сверяют манифест, а не похожесть текста. Это вопрос честности, а
не проверки.

## Доказательства вместо процентов

Проект намеренно отказался от приёмочной матрицы на полторы тысячи вызовов в
пользу проверки делом: дамп промпта плюс несколько живых запросов на том
хосте, где скилл будет жить. Обоснование — в [PLAN-1.0.md](docs/PLAN-1.0.md).

Если добавляете утверждение о поведении — приложите доказательство, на которое
можно сослаться. Пустая строка в чек-листе означает «не сделано», а не
«наверное в порядке».

## Стиль сообщений коммитов

Сообщение объясняет **почему**, а не пересказывает диff. Если правка чинит
дефект — назовите наблюдаемый симптом и причину. Коммиты, как и любые
сохраняемые артефакты, остаются чистыми: мат живёт в разговоре, а не в
истории.
