# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/spec/v2.0.0.html).

Датированный заголовок версии появляется только в момент релиза, вместе с
подтверждёнными доказательствами приёмки. До тех пор всё лежит в `[Unreleased]`.

## [Unreleased]

### Added

- Канонический скилл `koroche-blyat` как единственный источник семантики, плюс
  четыре справочника, написанных с нуля: сжатие, словарь, сцены, онтология.
- Детерминированный генератор адаптеров: постоянная политика, напоминание и
  стиль вывода Claude выводятся из байтов `SKILL.md` и несут его SHA-256.
- Постоянно включённый адаптер Prime Agent на событии `before_agent_start`,
  который добавляет политику ровно один раз и не переписывает ответ ассистента.
- Байт-идентичные POSIX-хуки `UserPromptSubmit` для Codex CLI и Claude Code:
  stdin поглощается и никогда не отражается, выход всегда `0`.
- Транзакционный установщик на Python 3.9 без сторонних зависимостей:
  побайтово сохраняющие правки маркерных блоков и JSON, список владения,
  журнал с резервными копиями, проверка после применения и откат в обратном
  порядке.
- Строгие схемы оценок и детерминированный грейдер: атомарные факты, защищённые
  байты со счётчиком вхождений, правила порядка, форма простого ответа, язык,
  стиль и жёсткие границы.
- Корпус релиза: двенадцать простых технических тем с разными языками ввода,
  десять уровней тяжести, девятнадцать категорий защищённых данных, семь классов
  чистых артефактов, три диалога со сменой области, четыре поверхности
  устойчивости Prime и парные токен-сессии.
- Офлайн-валидатор репозитория из девяти упорядоченных проверок и
  воспроизводимая сборка релиза: две сборки под одним `SOURCE_DATE_EPOCH` дают
  побайтово одинаковые `.tar.gz`, `.zip` и `SHA256SUMS`.
- Провенанс с закреплёнными коммитами апстримов и распространяемыми лицензиями
  Caveman и Pohuy.
- CI на GitHub Actions: проверка на Ubuntu и macOS для Python 3.9 и текущего,
  еженедельная сверка закреплённых апстримов и релизный workflow по тегу,
  который собирает, аттестует, выкладывает черновик, скачивает его обратно и
  заново сверяет суммы. Публикация остаётся ручной.

### Security

- Установщик работает офлайн и владеет только тем, что создал сам.
- Проверка апстримов по сети включается явным флагом, ходит только на
  `raw.githubusercontent.com` по 40-символьному коммиту и отклоняет
  перенаправления за пределы этого хоста.
- Хуки не встраивают текст политики и не отражают пользовательский ввод.

### Changed

- Скилл переклассифицирован в обычный Agent Skill: `description` во
  фронтматтере теперь описывает, **когда** его применять, а не заявляет
  универсальность. Постоянные адаптеры стали опцией для гарантии срабатывания
  и для Codex и Prime, где механизма скиллов нет.
- Словарь идиом расширен: варианты на каждом из десяти уровней, одиннадцать
  глаголов состояния, смягчённый ряд и правила сочетаемости. Всё написано
  заново, без заимствований из несвободных источников.

### Notes

- Фиксированный процент экономии токенов для 1.0.0 не заявляется. Публичная
  цифра появится только по воспроизводимым парным измерениям.
- Постоянного переключателя стиля в 1.0 нет: полное отключение — это удаление.
