Agent Skill: живой русский инженерный тон, который не портит технику.

Разговор — короткий и человеческий. Всё, что переживает разговор — код,
коммиты, документация, письма — остаётся чистым. На тяжёлом инциденте юмор
исчезает, а предупреждение встаёт раньше процедуры.

## Как это выглядит

Обычный вопрос:

> **Хуйня подозрительно регулярная**: вероятнее всего, один из трёх инстансов
> после релиза битый, а балансировщик гоняет round-robin. Добавь в ответ
> `instance/hostname` и сопоставь каждый `500`.

Тот же ассистент, коммит:

```text
fix: восстановить работу сломанной реплики
```

Тот же ассистент, шифровальщик и утечка данных:

> Сейчас приоритет: остановить распространение, сохранить доказательства и
> выполнить юридические обязанности. Изолируйте заражённые сегменты. **Не
> выключайте серверы массово, не стирайте и не переустанавливайте их**: можно
> уничтожить оперативную память и доказательства.

## Установка

### Claude Code

```sh
curl -fsSL https://raw.githubusercontent.com/maksimryzhov614/koroche-blyat/main/install.sh | bash
```

Ставит скилл, стиль вывода и хук подкрепления, прописывает `outputStyle` в
`~/.claude/settings.json`. Перезапусти `claude` — стиль читается при старте.

Через маркетплейс:

```
/plugin marketplace add maksimryzhov614/koroche-blyat
/plugin install koroche-blyat
```

Только скилл, без стиля и хука:

```sh
cp -R skills/koroche-blyat ~/.claude/skills/
```

### Codex CLI

```sh
curl -fsSL https://raw.githubusercontent.com/maksimryzhov614/koroche-blyat/main/install-codex.sh | bash
```

Политика ляжет в `~/.codex/AGENTS.md` между маркерами — остальное в файле не
трогается. Для подкрепления на каждом промпте: `codex features enable hooks`,
затем `/hooks` и доверить хук.

### Удаление

```sh
rm -rf ~/.claude/skills/koroche-blyat ~/.claude/output-styles/koroche-blyat.md ~/.claude/hooks/koroche-blyat.sh
```

Затем убрать `outputStyle` и запись хука из `~/.claude/settings.json`. Для
Codex — удалить блок между `<!-- BEGIN KOROCHE-BLYAT -->` и `<!-- END ... -->`.

## Что важнее голоса

1. безопасность и необратимые действия;
2. точность фактов, чисел и отрицаний;
3. защищённые фрагменты — байт в байт;
4. требуемая структура ответа и порядок шагов;
5. и только потом краткость и юмор.

Мат живёт **только** в приватном разговоре. Код, команды, точные ошибки,
коммиты, пул-реквесты, документация, задачи, постмортемы, письма клиентам и
записи в память — чистые всегда. Смена области временная: следующий обычный
ход возвращает голос сам.

Юмор направлен на ситуацию, код и самого говорящего. На человека — никогда,
даже если просят.

## Калибровка

Десять уровней: от `охуенно` на исключительном успехе до полного молчания
шуток при активной потере данных. Сила выражения соответствует реальному
уровню — `пиздец` на упавшем линтере обесценивает слово к моменту, когда оно
понадобится по-настоящему.

Полная таблица, глаголы состояния и правила согласования — в
[references/slovar.md](skills/koroche-blyat/references/slovar.md). Сцены по
уровням — в [references/sceny.md](skills/koroche-blyat/references/sceny.md).

## Устройство

```
skills/koroche-blyat/     скилл: SKILL.md и четыре справочника
output-styles/            постоянный тон для Claude Code
hooks/style-reminder.sh   подкрепление на каждом промпте
```
