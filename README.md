# koroche-blyat

> **Предупреждение о ненормативной лексике.** Скилл сознательно использует мат
> в обычном разговоре. Если это неприемлемо для вас или вашей команды — не
> устанавливайте его.

**Agent Skill**: русский инженерный голос, который не портит технику. Ответы
становятся короче и живее, а факты, порядок шагов и защищённые фрагменты
остаются нетронутыми.

Ядро — один файл `skills/koroche-blyat/SKILL.md` и четыре справочника. Всё
остальное в репозитории существует ради одного: сделать срабатывание
гарантированным и распространить его на Codex CLI и Prime Agent, где механизма
скиллов нет.

Поддержка: Claude Code как скилл; Prime Agent, Codex CLI и Claude Code — с
адаптерами.

## Как это выглядит

Обычный чат:

> **Хуйня подозрительно регулярная**: вероятнее всего, один из трёх инстансов
> после релиза битый, а балансировщик гоняет round-robin. Добавь в ответ
> `instance/hostname` и сопоставь каждый `500`.

Тот же ассистент, коммит:

```text
fix: восстановить работу сломанной реплики
```

Тот же ассистент, утечка данных и шифровальщик:

> Сейчас приоритет: остановить распространение, сохранить доказательства и
> выполнить юридические обязанности. Изолируйте заражённые сегменты. **Не
> выключайте серверы массово, не стирайте и не переустанавливайте их**: можно
> уничтожить оперативную память и доказательства.

Разговор — живой. Всё, что переживает разговор, — чистое. На катастрофе юмор
исчезает, а предупреждение стоит раньше процедуры.

## Что важнее голоса

Приоритет жёсткий и в таком порядке:

1. безопасность и необратимые действия;
2. точность фактов, чисел и отрицаний;
3. защищённые фрагменты — байт в байт, включая юникод-края;
4. требуемая структура ответа и порядок шагов;
5. и только потом краткость и юмор.

Мат допустим **только** в приватной разговорной части. Код, команды,
идентификаторы, точные ошибки, коммиты, пул-реквесты, документация, задачи в
трекере, постмортемы, письма клиентам и записи в память — чистые всегда. Смена
области временная: следующий обычный ход возвращает голос сам.

Юмор направлен на ситуацию, код и самого говорящего — никогда на названного
человека, даже если вас об этом просят.

## Установка

### Claude Code, одной командой

```
/plugin marketplace add maksimryzhov614/koroche-blyat
/plugin install koroche-blyat
```

### Или копированием папки

```sh
cp -R skills/koroche-blyat ~/.claude/skills/
```

Оба способа дают обычный скилл: срабатывание решает модель по описанию, и
работает это только в Claude Code.

### Постоянные адаптеры, все три хоста

```sh
tar -xzf koroche-blyat-1.0.0.tar.gz
cd koroche-blyat-1.0.0
./install.sh --dry-run --all
./install.sh --all
```

Здесь политика доезжает гарантированно и на Prime Agent, Codex CLI и Claude
Code. `--dry-run` печатает план и не пишет ни байта.

Полная последовательность с проверкой контрольных сумм, ручными действиями
после установки и удалением — [docs/INSTALL.md](docs/INSTALL.md).

## Обновление и удаление

```sh
./install.sh --all          # обновление на месте
./install.sh --uninstall --all
```

`npx skills update` обновляет каталог скиллов, но **не обновляет** постоянные
адаптеры: расширение Prime, хуки и стиль вывода ставятся установщиком и
обновляются только им. Подробности — [docs/UPDATING.md](docs/UPDATING.md).

Установщик владеет только тем, что создал сам, и хранит список владения.
Удаление трогает лишь эти записи; ваши правки рядом остаются байт в байт.

## Приватность

Скилл не делает сетевых запросов во время работы: это текстовая политика,
которую хост подмешивает в свой промпт. Установщик тоже работает офлайн. Сеть
нужна ровно один раз — скачать архив релиза.

## Измеренные результаты

Поведение проверяется детерминированным грейдером на зафиксированном корпусе:
защищённые байты и критические факты — 100%, общее покрытие фактов — не ниже
98%, форма простого ответа — не ниже 95%.

**No fixed token-saving percentage is claimed for 1.0.0.** Расход токенов
измеряется парным бутстрапом, и публичная цифра появится только тогда, когда
нижняя граница доверительного интервала окажется выше нуля на воспроизводимых
данных. Оценки «на глаз» в документацию не попадают.
