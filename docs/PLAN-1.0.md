# План 1.0: довести до работающего состояния

Заменяет исполнительную часть `docs/superpowers/plans/2026-08-12-koroche-blyat.md`
для выпуска 1.0. Тот план строил аппарат измерений; этот доводит продукт.

## Почему план другой

Три свойства продукта — живой тон, чистые артефакты, калибровка тяжести —
подтвердились на живой машине **за три запроса к Codex** после установки. Ни
950 захваченных вызовов, ни спроектированная матрица на 1650 их не
подтверждали: они давали проценты по регулярным выражениям, а измерительный
инструмент вдобавок подмешивал в выборку собственный нарратив агента.

Отсюда правило этого плана: **проверка делом на том хосте, где скилл будет
жить.** Никаких плечей, грейдеров и бутстрапов в критерии готовности.

## Критерий готовности

Для каждого поддерживаемого хоста выполнены три пункта:

1. **Инъекция доказана дампом** — канонический SHA присутствует в том, что
   реально видит модель, ровно один раз. Самоотчёт модели доказательством не
   считается.
2. **Три живых запроса дают верное поведение** — обычная отладка отвечает
   живым тоном; запрошенный артефакт выходит чистым; на максимальной тяжести
   юмор исчезает, предупреждение стоит раньше процедуры.
3. **Круговая установка и удаление** не оставляют следов: дерево возвращается
   к исходному состоянию побайтово.

Хост, где какой-то пункт не выполнен, документируется как `DEGRADED` или
`UNSUPPORTED` с причиной. Ложного «поддерживается» не бывает.

## Шаг 1. Codex — закрыть последний пункт

Состояние: инъекция доказана (`codex debug prompt-input`, SHA ровно один раз),
три живых запроса пройдены, круговая установка проверена на macOS.

Осталось ручное действие, которого установщик обойти не может:

```sh
codex features enable hooks
codex          # затем /hooks и доверить koroche-blyat
```

Проверка: после доверия хук подмешивает напоминание на каждый промпт. До него
базовая политика работает через `AGENTS.md`, состояние `DEGRADED`.

## Шаг 2. Claude Code — проверить в новом процессе

Стиль вывода читается при старте процесса, поэтому нужен свежий запуск.

1. Открыть новый `claude`, задать обычный технический вопрос.
2. Снять доказательство инъекции: `claude --debug-file` и найти в логе
   канонический SHA либо текст политики.
3. Прогнать те же три запроса, что и на Codex.

Отдельный вопрос: установленная версия 2.1.231 новее проверенной 2.1.197.
Либо поднять проверенную границу и записать это в фикстуру возможностей и
`COMPATIBILITY.md`, либо оставить `DEGRADED`. Молча считать новее значит
подтверждённым — нельзя.

## Шаг 3. Prime Agent — проверить впервые

Расширение установлено, но живьём не проверялось ни разу; юнит-тесты идут
против поддельного `ExtensionAPI` и заменой не являются.

1. Снять системный промпт расширением-перехватчиком в изолированном каталоге
   конфигурации, убедиться в единственном вхождении SHA и в том, что исходный
   промпт остался префиксом.
2. Те же три живых запроса.

Известная помеха: захват конкурирует с демоном. Проводить, когда никакие
прогоны не идут.

## Шаг 4. Linux — круговая установка

CI на Ubuntu сейчас выполняет только сухой прогон. Довести шаг до полного
цикла установки, обновления и удаления во временном HOME и сверки дерева.
Это единственный оставшийся пункт, который закрывается автоматикой, а не
руками, потому что Linux локально недоступен.

## Шаг 5. Прожить рабочий день

Пользоваться установленным скиллом в обычной работе и записывать:

- где тон мешает, а где помогает;
- случаи, когда мат просочился в артефакт (это дефект уровня релиза);
- случаи, когда юмор появился на тяжёлом инциденте (то же);
- места, где ответ стал короче ценой потерянного факта.

Это единственный способ узнать, хорош ли продукт. Регулярные выражения на
такой вопрос не отвечают.

## Шаг 6. Выпуск

1. Обновить `docs/RELEASE-CHECKLIST.md` по фактическим доказательствам.
2. Перенести `[Unreleased]` в `[1.0.0]` с датой выпуска.
3. Поставить тег `v1.0.0`; workflow соберёт, аттестует и выложит **черновик**.
4. Скачать черновик, сверить суммы на macOS и Linux.
5. Опубликовать — **решение человека**, автоматика до публикации не доходит.

## Что вынесено за пределы 1.0

| Что | Почему |
| --- | --- |
| Приёмочная матрица ~1650 вызовов | даёт проценты, а не понимание; три запроса дали больше |
| Исследование расхода токенов | существует ради цифры, которую проект сам себе запретил заявлять |
| Порог согласия судьи 0.90 | судью никто не запускает |
| Досъёмка плечей `core-only` и `full-skill` | инструмент измерения загрязняет выборку нарративом агента |

Код этих частей остаётся в репозитории и покрыт тестами. Не выполняются
только прогоны.

## Чего сознательно не трогаем

отработал: 44 записи владения, чужой `AGENTS.md` вырос с 7806 до 17929 байт
без потери исходного содержимого. Переписывать ради меньшего размера — риск
регрессии без выгоды.
