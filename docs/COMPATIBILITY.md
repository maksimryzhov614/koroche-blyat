# Совместимость

## Состояния

| Состояние | Что означает |
| --- | --- |
| `Supported` | обычный запуск хоста получает политику через документированный канал |
| `Verified` | состояние подтверждено сырым доказательством на закреплённой версии, а не самоотчётом модели |
| `Degraded` | политика доходит частично или требует ручного действия; результат виден, не выдаётся за успех |
| `Unsupported` | канал недоступен; ложного «всё хорошо» не будет |

Понятие «всегда включено» относится к обычным поддерживаемым запускам. Явные
пользовательские обходы и политика более высокого приоритета его отменяют — и
это честно сообщается, а не скрывается.

## Каналы внедрения

| Хост | Минимальная версия | Канал | Проверено на |
| --- | --- | --- | --- |
| Prime Agent | 0.7.1 | глобальное расширение, событие `before_agent_start` | 0.7.2 |
| Codex CLI | 0.147.0 | активный `AGENTS.override.md` либо `AGENTS.md` плюс хук `UserPromptSubmit` | 0.147.0 |
| Claude Code | 2.1.197 | стиль вывода с `keep-coding-instructions: true` плюс хук `UserPromptSubmit` | 2.1.197 |

Более новая версия хоста считается непроверенной, а не автоматически
поддержанной.

## Ручные действия

Codex требует доверить хук вручную через `/hooks`; привязка идёт к хешу
определения, поэтому обновление хука требует повторного подтверждения. Это
модель безопасности Codex — установщик её не обходит. До подтверждения
состояние `Degraded`: поведение приходит из глобального файла инструкций.

## Известные обходы

| Обход | Хост | Состояние |
| --- | --- | --- |
| `--no-extensions` | Prime Agent | `Unsupported` — расширение не загружается |
| `--no-context-files` | Prime Agent | `Degraded` — контекстные файлы игнорируются |
| `--safe-mode` | Claude Code | `Unsupported` — хуки и стиль отключены |
| `--bare` | Claude Code | `Unsupported` |
| отключённые хуки | Codex, Claude Code | `Degraded` |

## Приоритет политики

Управляемая (managed) политика организации и политика уровня проекта имеют более
высокий приоритет, чем пользовательские настройки. Если такая политика
конфликтует, она выигрывает: «всегда включено» не может и не должно её
пересиливать. Проект на местном уровне может переопределить стиль вывода
одноимённым файлом.

Это ограничение по устройству, а не дефект. Любой такой случай отражается как
`Degraded` или `Unsupported` с указанием причины.

## Несколько скиллов рядом

Пакет не переписывает ответ ассистента и не регистрирует обработку вывода. Он
добавляет текст политики к системному промпту и сохраняет исходные байты промпта
как префикс, поэтому соседние скиллы и инструкции по коду продолжают работать.

## Автоматические задачи

Тихое поведение включается только наблюдаемым маркером `<scheduled-task>` или
переменной `KOROCHE_BLYAT_UNATTENDED=1`. Режимы `--print`, JSON и RPC сами по
себе не означают автоматический запуск, а упоминание маркера в переписке его не
включает.
