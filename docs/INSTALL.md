# Установка

> **18+.** Скилл использует мат в обычном разговоре. Код, коммиты,
> документация и любые сохраняемые артефакты остаются чистыми — но сам чат
> нет. Если это неприемлемо, дальше можно не читать.

Три способа. Первый — самый простой, третий — самый надёжный.

---

## 1. Claude Code, через маркетплейс

```
/plugin marketplace add maksimryzhov614/koroche-blyat
/plugin install koroche-blyat
```

Скилл появится в списке доступных. Обновление — той же командой `add`.

Удаление:

```
/plugin uninstall koroche-blyat
```

## 2. Claude Code, копированием папки

Если не хотите подключать маркетплейс:

```sh
git clone https://github.com/maksimryzhov614/koroche-blyat.git
cp -R koroche-blyat/skills/koroche-blyat ~/.claude/skills/
```

Удаление — `rm -rf ~/.claude/skills/koroche-blyat`.

**Чем этот способ отличается от третьего:** здесь модель сама решает по
описанию, подгружать скилл или нет. Обычно да, но без гарантии. И работает
только в Claude Code — у Codex CLI и Prime Agent механизма скиллов нет.

## 3. Постоянные адаптеры, все три хоста

Политика доезжает до модели **всегда**, без ключевой фразы, на Prime Agent,
Codex CLI и Claude Code.

### 3.1. Скачать релиз и суммы

```sh
curl -fLO https://github.com/maksimryzhov614/koroche-blyat/releases/download/v1.0.0/koroche-blyat-1.0.0.tar.gz
curl -fLO https://github.com/maksimryzhov614/koroche-blyat/releases/download/v1.0.0/SHA256SUMS
```

Ссылка привязана к тегу, а не к ветке: содержимое по этому адресу не меняется.

### 3.2. Проверить контрольную сумму

```sh
shasum -a 256 -c SHA256SUMS      # macOS
sha256sum -c SHA256SUMS          # Linux
```

Не сошлось — остановитесь и не распаковывайте.

### 3.3. Посмотреть, что внутри

```sh
tar -tzf koroche-blyat-1.0.0.tar.gz
```

Внутри только скилл, сгенерированные адаптеры, установщик и лицензии. Ни
бинарников, ни сетевых компонентов.

### 3.4. Сухой прогон

```sh
tar -xzf koroche-blyat-1.0.0.tar.gz
cd koroche-blyat-1.0.0
./install.sh --dry-run --all
```

Печатает план в JSON и **не создаёт ни одного файла**, включая служебные.
Значения ваших конфигов в вывод не попадают.

### 3.5. Установить

```sh
./install.sh --all
```

Отдельные хосты: `--prime`, `--codex`, `--claude` в любом сочетании.

Установка транзакционная: сначала резервные копии и журнал, затем запись, затем
проверка результата. При любой ошибке всё откатывается в обратном порядке.

## После установки

### Codex CLI: доверить хук вручную

Это модель безопасности Codex, установщик её не обходит:

```sh
codex features enable hooks
codex
```

В сессии выполнить `/hooks` и доверить `koroche-blyat`. До этого базовая
политика работает через `AGENTS.md`, а состояние считается `DEGRADED`.

### Claude Code: перезапустить процесс

Стиль вывода и список скиллов читаются при старте. Текущая сессия их не
подхватит — откройте новый `claude`. Хуки, в отличие от них, работают сразу.

### Проверить, что политика доехала

Не верьте самоотчёту модели — посмотрите, что она реально видит:

```sh
codex debug prompt-input "проверка" | grep -c canonical-sha256
```

Должно быть ровно `1`.

## Обновление

```sh
./install.sh --all
```

Обновляются все ранее установленные хосты, даже если сейчас вы их не
перечислили. Повторная установка той же версии — пустая операция.

`npx skills update` обновляет каталог скиллов, но **не трогает** адаптеры:
расширение Prime, хуки и стиль вывода ставятся установщиком.

## Удаление

```sh
./install.sh --uninstall --all
```

Удаляются только записи из списка владения. Ваши правки в тех же файлах
сохраняются байт в байт. Если вы меняли файл, которым владеет установщик,
обычное удаление остановится и скажет об этом; `--force` снимет владение с
этого конкретного ресурса, не трогая остальное.

## Коды возврата

| Код | Значение |
| --- | --- |
| 0 | успех, отсутствие изменений или сухой прогон |
| 1 | сбой во время работы, изменения откачены |
| 2 | ошибка аргументов, предполётной проверки или владения |
| 3 | откат не завершён; пути журнала и резервных копий напечатаны |

Код 3 — единственный случай, требующий вмешательства руками. Журнал и
резервные копии остаются на диске, их пути печатаются.
