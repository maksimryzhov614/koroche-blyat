| Прогон | Результат |

Ноги: `ubuntu-latest`×3.9, `ubuntu-latest`×3.13, `macos-latest`×3.9,
`macos-latest`×3.13. На Linux тем самым подтверждены офлайн-гейты, полный
набор тестов, байт-идентичность двух сборок и сухой прогон из распакованного
артефакта с нулём записей в HOME.

Чего Linux **не** подтвердил: полного цикла установки, обновления и удаления.
Шаг CI выполняет только `--dry-run`, поэтому строка о круговой проверке на
Linux остаётся невыполненной, а не закрывается ссылкой на зелёный прогон.

Круговая проверка на macOS выполнена из распакованного `koroche-blyat-1.0.0.tar.gz`,

## Ручные действия при установке

Codex требует доверить хуки вручную: `codex features enable hooks`, затем
`/hooks`. До этого установщик сообщает `DEGRADED`, и это не считается успехом.

выкладывает, скачивает обратно и заново сверяет суммы — и останавливается.
